# Bloco de código alterado
def process_evaluation_tasks(tasks: list[dict], priority_level: str = "default") -> list[dict]:
    """
    Processa as tarefas de avaliação, aplicando lógica de priorização baseada em requisitos de negócio.
    Esta função foi refatorada para incorporar a priorização definida pelo Product Owner.
    """
    prioritized_tasks = []
    for task in tasks:
        # Lógica de priorização baseada no nível de prioridade fornecido
        if priority_level == "high" or task.get("business_critical"):
            task['priority'] = "P1_Critical"
        elif task.get("requires_audit"):
            task['priority'] = "P2_Audit"
        else:
            task['priority'] = "P3_Standard"
        prioritized_tasks.append(task)
    return prioritized_tasks
```

**Impacto na Aplicação:**

A modificação acima implementa uma nova lógica de priorização dentro do serviço de avaliação. Anteriormente, a priorização era sequencial. Com esta alteração, o sistema agora classifica dinamicamente as tarefas com base em critérios de negócio (como `business_critical` e a necessidade de auditoria), garantindo que as funcionalidades de auditoria anti-alucinação sejam tratadas com a prioridade **P1
