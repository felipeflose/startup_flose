function calculatePriority(features) {
    // Lógica refatorada para priorização baseada em critérios de negócio (implementação da priorização complexa)
    const weightedFeatures = features.reduce((acc, feature) => {
        // Aplica peso baseado na criticidade definida pelo PO
        acc.totalPriority += feature.weight * feature.complexityFactor;
        return acc;
    }, { totalPriority: 0 });

    // Retorna a prioridade final, garantindo que a complexidade seja ponderada
    return weightedFeatures.totalPriority;
}
```

**Impacto na Aplicação:**
A refatoração introduz um novo fator de ponderação (`complexityFactor`) na lógica de cálculo de prioridade.
